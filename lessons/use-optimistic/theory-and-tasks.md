# Хук `useOptimistic`

## Теория

Хук `useOptimistic` (доступен в React 19) позволяет вам показывать "оптимистичное" состояние в пользовательском интерфейсе (UI) во время выполнения асинхронного действия. Это делает интерфейс более отзывчивым, так как изменения отображаются мгновенно, не дожидаясь ответа от сервера. Если сервер возвращает ошибку или действие завершается, состояние синхронизируется с реальными данными.

Синтаксис:
```tsx
const [optimisticState, addOptimistic] = useOptimistic(
  state,
  // updateFn
  (currentState, optimisticValue) => {
    // Возвращает новое оптимистичное состояние
    return newState;
  }
);
```

- `state`: Исходное истинное состояние, которое поступает сверху (или из локального состояния, синхронизированного с сервером).
- `updateFn`: Функция, которая берет текущее состояние и оптимистичное значение (переданное в `addOptimistic`), возвращая новое состояние для отображения.

Основной паттерн использования - внутри формы с серверными действиями (Server Actions) или асинхронными обработчиками:
1. Вызываете `addOptimistic(newValue)`.
2. UI мгновенно обновляется.
3. Выполняется асинхронный запрос к API.
4. При успешном завершении настоящее состояние `state` обновляется.
5. React автоматически отбрасывает `optimisticState` и возвращается к настоящему `state` (которое теперь включает изменения).

## Задача: Менеджер комментариев с оптимистичным UI

Вам необходимо реализовать систему комментариев, где добавление нового комментария, удаление и лайк комментария происходят оптимистично.

### Требования

1. **Отображение списка комментариев:**
   - Комментарий состоит из `id`, `text`, `likes`, `isSending` (опциональный флаг для оптимистичных элементов).
2. **Оптимистичное добавление:**
   - При отправке формы комментарий мгновенно появляется в списке с индикатором "Отправка...".
   - Имитируйте задержку сети (1-2 секунды) перед тем, как комментарий "сохранится".
3. **Оптимистичный лайк:**
   - При нажатии на кнопку лайка счетчик должен немедленно увеличиваться.
   - Имитируйте асинхронный запрос на сервер. Если запрос успешен - обновлять основное состояние, если нет (можно сделать вероятность ошибки 20% для полноты картины) - показать уведомление и откатить лайк (React сделает это автоматически при получении реального состояния).
4. **Оптимистично удаление:**
   - При нажатии на "Удалить" комментарий мгновенно исчезает из списка.
   - После успешного запроса на сервер он удаляется из основного списка.

### Шаги к выполнению

- Перейдите в файл `src/lessons/UseOptimistic/CommentManager.tsx` (создайте его).
- Используйте `useState` для хранения списка подтвержденных комментариев.
- Используйте `useOptimistic` для управления списком видимых пользователю комментариев (включая те, которые еще обрабатываются).
- Напишите Имитацию API (`fakeApi.addComment`, `fakeApi.likeComment`, `fakeApi.deleteComment`), возвращающие Promise с задержкой.
- Реализуйте функции для добавления, лайка и удаления, которые сначала вызывают метод оптимистичного обновления, а затем обращаются к API.
- Добавьте стили согласно AI Styling Guidelines.
