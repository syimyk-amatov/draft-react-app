# React Практика: useActionState Hook

## 1. Теория

### Проблема (Async Transition State)
При работе с асинхронными действиями (например, отправка формы, обновление данных на сервере) нам часто предстоит управлять тремя состояниями интерфейса:
1.  **Pending**: Данные отправляются, нужно показать спиннер или заблокировать кнопку.
2.  **Success**: Действие успешно выполнено, нужно обновить UI или показать сообщение.
3.  **Error**: Произошла ошибка, нужно показать её пользователю.

Раньше для этого приходилось вручную создавать состояния `isSubmitting`, `error`, `data` через `useState` и вручную переключать их внутри `try/catch`.

### Решение (useActionState)
`useActionState` — это хук, добавленный в React 19, который упрощает обработку состояний для форм и других асинхронных действий. Он принимает функцию-"действие" (Action) и начальное состояние, а возвращает текущее состояние, функцию для запуска действия и флаг загрузки.

```tsx
const [state, formAction, isPending] = useActionState(fn, initialState, permalink?);
```

*   **fn**: Функция, которая вызывается при отправке формы или нажатии кнопки. Она получает `previousState` (предыдущее состояние) и `formData` (данные формы).
*   **initialState**: Значение состояния до первого вызова действия.
*   **state**: Текущее состояние, возвращённое функцией `fn`.
*   **formAction**: Функция, которую нужно передать в проп `action` формы или вызвать вручную.
*   **isPending**: Булево значение, указывающее, выполняется ли сейчас переход (action).

**Пример:**
```tsx
async function increment(previousState, formData) {
  return previousState + 1;
}

function Counter() {
  const [state, formAction, isPending] = useActionState(increment, 0);
  return (
    <form action={formAction}>
      {state}
      <button disabled={isPending}>Increment</button>
    </form>
  );
}
```

## 2. Задача 1: Форма обновления профиля (Form Actions)

Освойте работу с формами и состоянием загрузки.

### Сценарий
Пользователь хочет обновить свое имя пользователя. Это асинхронная операция, которая может занять время.

### Требования:
1.  Создайте компонент `UpdateProfileForm`.
2.  **Action**: Напишите асинхронную функцию `updateNameAction(prevState, formData)`, которая:
    *   Получает новое имя из `formData` (поле `username`).
    *   Имитирует задержку сети (`await new Promise(...)` на 1-2 сек).
    *   Возвращает объект состояния: `{ success: boolean, message: string, currentName: string }`.
    *   Если имя пустое — возвращает ошибку.
3.  **UI**:
    *   Форма с одним инпутом `name="username"`.
    *   Кнопка "Обновить".
    *   Текст текущего имени (берется из state).
4.  **Логика**:
    *   Передайте `formAction` в тег `<form action={...}>`.
    *   Используйте `isPending`, чтобы:
        *   Заблокировать кнопку (disabled).
        *   Изменить текст кнопки на "Обновление...".
    *   Отобразите сообщение об успехе или ошибке из `state` под формой.

## 3. Задача 2: "Лайк" с оптимистичным и реальным состоянием

Попробуйте использовать `useActionState` для взаимодействия вне контекста стандартной HTML-формы, используя скрытые инпуты или привязку аргументов.

### Сценарий
Кнопка "Like" под постом. Мы хотим отправить лайк на сервер и получить обновленное количество лайков.

### Требования:
1.  Создайте компонент `LikeButton`.
2.  **State**: `{ likes: number, error: null | string }`. Начальное: `{ likes: 42, error: null }`.
3.  **Action**: Функция `likeAction(prevState, formData)`, которая:
    *   Имитирует запрос к серверу.
    *   Успешный сценарий (80% случаев): возвращает `{ likes: prevState.likes + 1, error: null }`.
    *   Сценарий ошибки (20% случаев): возвращает `{ likes: prevState.likes, error: "Не удалось лайкнуть" }`.
4.  **UI**:
    *   Кнопка с иконкой сердца и количеством лайков.
    *   Если `isPending`, кнопка становится полупрозрачной или показывает спиннер, но *не блокируется* полностью (визуальный отклик).
    *   Если есть ошибка, показать её красным текстом рядом с кнопкой.
5.  **Дополнительно (Challenge)**:
    *   Попробуйте реализовать toggle (Лайк / Убрать лайк) в одной функции, опираясь на текущее состояние.
